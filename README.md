 💳 Credit Risk Prediction Web App

This is a Machine Learning web application that predicts whether a customer is risky or safe based on financial details.

## 🚀 Features
- Predict credit risk using ML model (KNN)
- Interactive UI using Streamlit
- Real-time input for age, income, loan amount, credit score
- Deployed on Streamlit Cloud

## 🛠️ Tech Stack
- Python
- Streamlit
- Scikit-learn
- Pandas, NumPy
